# SEO ТЗ генератор

Веб-сервіс, який складає ТЗ копірайтеру на SEO-тексти за аналізом ТОПу Google (Україна).

**Як працює**

1. Ви завантажуєте семантику (xlsx з аркушами `ua` / `ru` або текстом). Кожен кластер — це одна сторінка.
2. Сервіс сам підбирає пари кластерів UA ↔ RU. Ви перевіряєте пари і за потреби додаєте примітку до сторінки.
3. Для кожної сторінки та мови:
   - **Serper.dev** знімає видачу Google UA: ТОП-10, «Люди також питають», пов’язані запити;
   - сервіс завантажує сторінки конкурентів і рахує H1–H3, обсяг основного контенту, FAQ, ціни, входження ключів і кандидатів у LSI з діапазонами;
   - **Claude** визначає інтент і шаблон, обсяг, структуру з коментарями (обов’язкові блоки + прогалини ТОПу), ключі, LSI, FAQ, Title/Description, ризики канібалізації.
4. На виході Excel у двох форматах, обираєте галочками:
   - **Advanced** — детальне ТЗ: зведення, методика, аналіз ТОПу, аркуш на кожну сторінку × мову (мета, структура, ключі + LSI, семантика кластера);
   - **Base** — формат «як у прикладі»: структура з червоними коментарями, праворуч ключі з частотою.

## Автоматичний збір семантики

Вкладка «Зібрати автоматично»: один рядок — одна послуга (назва) або URL сторінки-прикладу.

1. Claude формує 10–15 сидів для кожної мови і мінус-слова. Якщо дано URL, сервіс спершу читає сторінку.
2. Сиди розширюються підказками Google (Serper Autocomplete), «Пов’язаними запитами» з видачі та ідеями Google Ads (DataForSEO `keywords_for_keywords`).
3. Частотність по Україні для кожної мови береться з Google Ads / Keyword Planner через DataForSEO `search_volume`.
4. Claude чистить кандидатів (інтент, мінус-слова, мова, дублі) і розкладає їх: основна сторінка + до 4 запропонованих додаткових сторінок.
5. Результат можна завантажити як `Semantics.xlsx` у форматі «кластер / ключ / частотність», а також питання з «Люди також питають». Кнопка «Взяти в роботу» переносить семантику в таблицю сторінок. Ключі кожної сторінки можна відредагувати: клік по колонці «Ключі».

Без DataForSEO ключі теж зберуться, але без частотності.

Вартість DataForSEO: $0.09 за live-запит до 1000 ключів, тобто ≈ $0.2–0.4 на послугу (дві мови).

## Локальний запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заповніть ключі
export $(grep -v '^#' .env | xargs)
uvicorn app.main:app --reload
```

Відкрийте http://localhost:8000. Для перевірки інтерфейсу без ключів: `MOCK=1 uvicorn app.main:app`.

Тести: `pytest -q`.

## Деплой на Railway

1. Railway → **New Project** → **Deploy from GitHub repo** → оберіть цей репозиторій. Railway збере проєкт за `Dockerfile` (налаштування в `railway.json`).
2. **Variables** — додайте змінні:

| Змінна | Обов’язково | Опис |
|---|---|---|
| `ANTHROPIC_API_KEY` | так | ключ Claude API (console.anthropic.com) |
| `SERPER_API_KEY` | так | ключ serper.dev |
| `APP_PASSWORD` | так | пароль входу в інтерфейс |
| `SECRET_KEY` | так | довгий випадковий рядок для cookie |
| `DATAFORSEO_LOGIN` / `DATAFORSEO_PASSWORD` | для збору семантики | частотність Google Ads (app.dataforseo.com → API Access) |
| `ANTHROPIC_MODEL` | ні | за замовчуванням `claude-sonnet-4-5` |
| `MAX_COMPETITORS` | ні | скільки сторінок ТОПу парсити на запит (6) |
| `PARALLEL_CLUSTERS` | ні | скільки сторінок обробляти паралельно (2) |

3. **Volume.** Сервіс → **Settings → Volumes** → змонтуйте volume у `/data`. Без нього історія задач і файли зникнуть після передеплою.
4. **Settings → Networking → Generate Domain**, щоб отримати публічну адресу.

Перевірка, що сервіс піднявся: `GET /api/health` повертає, чи задані ключі.

## Формат семантики

**xlsx.** Аркуші `ua` і `ru` (або одна таблиця з колонкою «Мова»). Колонки знаходяться за заголовками: `кластер`, `ключове слово`, `частотність`. Назву кластера можна писати окремим рядком над його ключами, як у файлі «нова семантика 2026». Приклад файлу можна завантажити в інтерфейсі.

**Текст.**
```
# SERM
serm послуги; 40
управління репутацією в інтернеті; 30
```

## Вартість одного ТЗ (орієнтовно)

- **Serper:** 1–2 запити на мову, тобто 2–4 запити на сторінку (≈ $0.004).
- **Claude:** один виклик на сторінку, ~15–25 тис. вхідних і ~6–10 тис. вихідних токенів.
- **Час:** 1–3 хв на сторінку.

## Структура

```
app/
  main.py        маршрути FastAPI, авторизація
  semantics.py   розбір xlsx/тексту, автопари UA↔RU
  collect.py     автоматичний збір семантики (сиди → розширення → частотність → чистка)
  volumes.py     DataForSEO (Google Ads) + Serper Autocomplete
  serp.py        Serper.dev
  scraper.py     завантаження та розбір сторінок ТОПу
  analysis.py    обсяги, входження ключів, LSI-кандидати
  prompts.py     методика + еталонне ТЗ (examples/serm.json) + схема відповіді
  llm.py         виклик Claude (structured output через tool use)
  excel.py       Excel Advanced / Base
  pipeline.py    оркестрація фонових задач
  db.py          SQLite (історія задач)
```

Методику (правила складання ТЗ) змінюють у `app/prompts.py`. Еталон якості лежить у `app/examples/serm.json`: якщо його замінити, зміниться стиль коментарів у ТЗ.
